# Site de Receitas – HTML e CSS

Este repositório contém um site de receitas desenvolvido com HTML e CSS, inspirado em plataformas culinárias como o TudoGostoso. O projeto tem como objetivo praticar e aprimorar conhecimentos em desenvolvimento web, organização de conteúdo e estilização de páginas, sendo realizado para fins acadêmicos e treinamento.

## Funcionalidades

- **Estrutura HTML:** Organização do conteúdo utilizando tags semânticas para melhorar a estrutura e a compreensão da página.
- **Estilização com CSS:** Aplicação de cores, fontes, espaçamentos e outros elementos visuais para criar uma interface agradável.
- **Exibição de Receitas:** Apresentação de receitas com títulos, imagens, ingredientes e modo de preparo.
- **Organização do Conteúdo:** Distribuição das informações em seções para facilitar a navegação e a leitura.
- **Imagens Responsivas:** Ajuste das imagens para manter uma boa apresentação dentro da página.
- **Navegação:** Utilização de links para facilitar o acesso às diferentes seções do site.

## Objetivo do Projeto

O projeto foi desenvolvido com finalidade acadêmica e de treinamento, visando consolidar conhecimentos fundamentais em HTML e CSS. Também busca desenvolver boas práticas de estruturação, semântica, organização e estilização de páginas web.

## Tecnologias Utilizadas

- **HTML5:** Estruturação e organização do conteúdo.
- **CSS3:** Estilização e apresentação visual das páginas.

## Como Executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador para visualizar o site.

## Aprendizados

Durante o desenvolvimento, são praticados conceitos como estrutura HTML, tags semânticas, formulários, seletores CSS, Flexbox, organização de arquivos e estilização de elementos.
